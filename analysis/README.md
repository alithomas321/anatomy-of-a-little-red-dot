# Analysis

Setup and the portable numerical reproduction commands are in the [project README](../README.md).

measure.py measures the two wavelength bands. shapes.py compares continuum shapes. amended_v2_extraction.py checks extraction choices; amended_v2_lines.py fits a finite line/continuum grid. The corresponding figure scripts render the results.

verify.py and verify_amended_v2.py preserve the original workspace audit logic. They also check private source-history and snapshot records omitted from this public package; use the public file manifest for package integrity.
